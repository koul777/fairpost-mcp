## 보강한 검사가 놓친 이유와 확인

P1, P2, P4는 이전 두 실행에서 자동 검사를 모두 통과했고 화면 판독 역할이 찾았음. 이유는 세 가지임. 생성 글자 검사가 `counter()` 숫자를 건너뛰었고, 입력 칸 글자는 표시 층이 아니라 입력 칸 자체의 글자라 표시 층 대비를 재는 검사가 없었고, `::selection`은 검사 대상이 아니었음. 이를 보강한 뒤에도 R1이 남았는데, 선택 색을 입력 칸 바탕 위에서만 재서 고른 표시 채움 위에 겹친 경우를 놓쳤기 때문임. 이제 선택 색을 모든 표시 채움 위에 겹쳐 재는 검사를 추가함.
