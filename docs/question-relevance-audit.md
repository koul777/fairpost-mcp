# 질문 관련성 감사

감사일: 2026-07-29

이 감사의 목적은 질문 수를 줄이는 것 자체가 아니라, 공고에서 바로 확인할
질문과 모든 채용 절차에 공통으로 적용할 체크리스트를 구분하고 명백한
오발동을 줄이는 것이다. 결과는 공정성ㆍ법 위반 판정이나 G1ㆍG2 성능
측정이 아니다.

## 데이터 경계

- PRD 학습 분할 420건만 사용했다.
- 경로에 `holdout`이 포함되면 감사 도구가 파일을 열기 전에 실행을 거부한다.
- 보고서에는 공고 원문, 레코드ㆍ출처 ID, 조직명, 개인식별정보를 기록하지
  않는다.
- 봉인 홀드아웃과 사람 라벨은 열거나 변경하지 않았다.

재현 명령은 다음과 같다.

```powershell
python tools\audit_question_relevance.py `
  --input .corpus-prd\train\records.jsonl `
  --output reports\question_relevance_audit.json
```

## 모델 보조 표본 검토

공공ㆍ민간과 질문 발동량 상ㆍ하를 나눈 4개 층에서 28건을 검토했다. 총
394개 질문 발동을 질문이 공고에 직접 근거하는지, 정보 부재로 발동하는지,
채용 전반의 공통 체크인지, 명백한 오발동인지, 포털 부가문구에 의한
오염인지로 모델 보조 분류했다. 이는 사람 정답 라벨이 아니며 집계 근거는
`reports/question_relevance_manual_review.json`에 원문과 식별자 없이
별도로 보존한다.

| 분류 | 발동 수 | 비율 |
|---|---:|---:|
| 공고 직접 근거 | 78 | 19.8% |
| 정보 부재 기반 | 144 | 36.5% |
| 공통ㆍ기관 운영 체크 | 130 | 33.0% |
| 명백한 오발동 | 25 | 6.3% |
| 포털ㆍ비공고 문구 오염 | 17 | 4.3% |
| 합계 | 394 | 100.0% |

공고별 질문 264개만 보면 명백한 오발동과 포털 오염은 42개, 15.9%였다.
이 표본은 개선 대상을 찾기 위한 진단 표본이며 정밀도 추정치로 사용하지
않는다.

## 적용한 변경

### 공고별 질문과 공통 체크리스트 분리

질문에 `review_scope`를 추가했다.

- `posting`: 해당 공고 결과에서 바로 검토할 질문
- `common`: 공고마다 반복되지만 채용 전반에서 한 번 확인하면 되는 기본
  체크리스트

공통으로 분류한 질문은 `Q-INFO-005`, `Q-INFO-007`, `Q-INFO-008`,
`Q-PROC-009`, `Q-PROC-013`이다. API의 `questions` 배열과
`counts.questions` 의미는 유지하고, 웹에서만 공통 체크리스트를 기본
접힘 상태로 분리했다. 후속 질문도 기본 접힘으로 바꿔 첫 화면의 검토량을
줄였다.

### 명백한 문맥 오발동 제외

학력ㆍ학교 기재 금지, 지역 제한 없음, 종교 기재 금지ㆍNCS 분류,
북한이탈주민 우대, 임금 면접 협의처럼 보호적이거나 관련 없는 문맥을
제외했다. 제한적 표현이 실제로 있는 양성 사례는 회귀 테스트로 보존했다.

| 질문 | 변경 전 발동 공고 | 변경 후 발동 공고 | 감소 |
|---|---:|---:|---:|
| `Q-DIST-005` | 10 | 3 | 7 |
| `Q-DIST-006` | 68 | 16 | 52 |
| `Q-DIST-012` | 14 | 0 | 14 |
| `Q-DIST-013` | 45 | 33 | 12 |
| `Q-PROC-011` | 191 | 172 | 19 |
| 합계 | 328 | 224 | 104 |

### 지원서와 증빙서류 질문 분리

최신 NCS 공정채용 모니터링 자료가 지원서 최소수집과 별도로 입증자료의
후속ㆍ최소 제출, 블라인드 처리와 평가위원 미제공을 제시하므로
`Q-INFO-010`의 `제출서류` 트리거를 제거하고 구체적인 증빙 표현에
`Q-INFO-011`을 연결했다.

| 질문 | 변경 전 발동 공고 | 변경 후 발동 공고 |
|---|---:|---:|
| `Q-INFO-010` 지원서 최소수집 | 186 | 137 |
| `Q-INFO-011` 증빙서류 단계ㆍ마스킹 | - | 58 |

단순 `제출서류` 표제 때문에 발생하던 지원서 질문은 줄고, 졸업ㆍ경력ㆍ자격
등 실제 증빙 표현이 있는 공고만 새 질문을 받는다. 두 질문의 순증가는
9개다.

2025 모니터링 PDF 11쪽의 복수 직렬 공통 지원서 사례는 전역 키워드
동시출현 대신 같은 `근무분야` 목록행, 600자 이내 교육정보, 5,000자
이내 지원서 단서를 모두 요구하는 `Q-INFO-012`로 구현했다. PRD train
420건에서 2건(0.5%), 민간 공개 train 2,100건에서 0건 발동했다.

## 결과

변경 전에는 420건에서 질문 발동이 5,763개, 공고당 평균 13.72개였고
모두 펼쳐져 있었다. 변경 후 전체 질문 발동은 5,670개이며, 이 가운데
공고별 질문은 3,575개, 공통 질문은 2,095개다.

공고별 질문 가운데 `Q-INFO-001`, `Q-INFO-004`, `Q-PROC-002`는 각각
이의제기 경로, 채용서류 반환ㆍ파기 안내, 평가 기준 슬롯과 1차 의미가
겹친다. 세 질문은 420건에서 합계 1,216회 발동하고 389건(92.6%)에서
동시에 발동했다. 질문을 삭제하거나 공통으로 바꾸지 않고, 웹에서 대응하는
`확인되지 않은 항목` 카드 안의 기본 접힘 상세로 이동했다. API,
`counts.questions`, 복사 의견서에는 계속 모두 포함된다.

| 지표 | 결과 |
|---|---:|
| 전체 발동 | 5,670개 |
| 공고별 질문 전체 | 3,575개, 공고당 8.51개 |
| 누락 항목 카드 안 기본 접힘 | 1,216개, 공고당 2.90개 |
| 첫 화면 기본 펼침 | 2,359개, 공고당 5.62개 |
| 공통 기본 접힘 | 2,095개, 공고당 4.99개 |
| 현재 전체 대비 기본 접힘 비율 | 58.4% |
| 변경 전 전체 펼침 대비 첫 화면 감소 | 59.1% |
| 명백한 문맥 오발동 감소 | 104개 |

데스크톱 1440×1000과 모바일 390×844에서 공통 체크리스트를 처음 적용한
화면을 점검했다. 두 화면 모두 공통 체크리스트 5개와 후속 질문 12개가
기본 접힘 상태였으며 가로 넘침이 없었다. 이후
추가한 누락 슬롯 안 질문 접힘은 train 420건의 세 쌍, 총 1,260개
slot-question 관계에서 불일치 0건으로 검증했다. 다만 이 추가 배치의
새 시각 캡처는 앱 내 브라우저 연결을 사용할 수 없어 보류하고, 스크립트
구문ㆍ정적 DOM 구조ㆍ반응형 CSS 회귀 검증으로 대체했다.

현재 규칙으로 재현되는 기계 판독 가능한 집계는
`reports/question_relevance_audit.json`에 저장한다. 이 보고서는 현재
질문 정의 42개별 발동률, `review_scope`ㆍ표시 그룹별 발동 수, 95% 이상
반복 질문을 원문 없이 기록한다. 변경 전 스냅샷과 모델 보조 표본 분류는
`reports/question_relevance_manual_review.json`에 분리해, 현재 집계와
과거 비교 근거를 혼동하지 않도록 했다.

## 보류한 항목

- `Q-INFO-001`, `Q-INFO-004`, `Q-PROC-002`는 학습 분할의 95% 이상에서
  발동하지만 정보 부재를 확인하는 질문이다. 사람 라벨 없이 공통으로
  이동하거나 비활성화하면 실제 누락을 가릴 수 있어 공고별 질문으로
  유지하고, 대응 슬롯 카드 안에서 펼쳐볼 수 있게 했다.
- 포털 머리말ㆍ꼬리말 제거는 질문을 바꾸는 공고가 420건 중 4건(1.0%),
  전체 findings까지 포함하면 5건(1.2%)이었다. 코퍼스 해시와 봉인 평가
  경계를 바꾸는 작업이므로 이번 변경에 포함하지 않았다.
- G1 정밀도와 G2 재현율ㆍ정밀도는 봉인 홀드아웃 사람 라벨이 준비된 뒤
  `tools/evaluate.py --enforce-targets`로만 판단한다.
