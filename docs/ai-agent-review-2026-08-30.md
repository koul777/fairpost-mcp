# Claude × Codex 제품 방향 합의

검토일: 2026-08-30
범위: FairPost v0.3 안전성 강화와 v1.0 진입 조건

## 참여와 방법

- Claude Code 2.1.251 Sonnet은 `docs/roadmap.md`, 완료ㆍ수용 감사,
  릴리스 보고서 생성기와 원격 MCP 코드를 읽기 전용으로 비판 검토했다.
- Codex는 코드ㆍ테스트ㆍ산출물을 점검하고 Claude의 반론을 구현과 계획에 반영했다.
- 별도 코드 에이전트는 CI 이식성, 규칙ㆍ데이터 증거, 비공개 공정성 감사 흐름을
  독립 검토했다. 사람 라벨이나 비공개 공고 원문을 대신 판단하지 않았다.

## 합의한 제품 방향

FairPost는 공정성 점수, 지원자 순위, 합격ㆍ위반 판정을 만드는 시스템이 아니다.
공고문에서 근거 표현과 누락 가능성을 결정론적으로 찾아 사람이 확인할 질문을
제공하는 감사 보조 도구로 유지한다.

기본 경로는 정적 웹ㆍCLIㆍ루프백 MCP처럼 on-device로 둔다. 네트워크 MCP는
사용자가 선택하는 확장 경로이며 읽기 전용 최소 권한으로 제한한다. 답변 저장은
루프백 로컬 MCP만 제공한다. Claude 호환 원격 경로도 기본 비활성화하고, Bearer
인증 또는 별도 공개 opt-in 없이는 열지 않는다.

자동 테스트 통과와 실제 성능 입증은 분리한다. 사람 라벨이 없는 train 분석과
synthetic 회귀 테스트는 개발 근거일 뿐 G1ㆍG2 성능 근거가 아니다.

## 주요 반론과 결정

| 쟁점 | Claudeㆍ에이전트 반론 | Codex 결정 |
|---|---|---|
| Claude 원격 경로 | 별도 `/api/claude-mcp`가 토큰과 무관하게 익명 공개됨 | 별도 opt-in 없이는 비활성화하고 토큰이 있으면 동일 Bearer 인증 적용 |
| 릴리스 명령 | 비엄격 보고서 생성 성공이 출시 가능으로 오인될 수 있음 | 기본 명령을 strict로 두고 후보 CI만 `--candidate-report`를 명시하며, strict 성공 없이는 v1 태그 금지 |
| 평가 순서 | holdout을 본 뒤 규칙을 수정하면 평가 누출 | train 검토→규칙 수정→버전 동결→독립 라벨링→holdout 1회 최종 평가 순으로 변경 |
| 0건 관찰 규칙 | 후보가 없는 규칙은 현재 최소 표본 게이트를 통과할 수 없음 | 정밀도 0 또는 통과로 만들지 않고 `coverage_gap`으로 유지해 출처ㆍ표본 보강 |
| 민간 대표성 | 3,000건이 단일 출처이고 직군 편중 | v0.3에서는 한계를 공개하고 v1.0은 계속 차단 |
| UI 검증 | UI 변경 후 현재 브라우저 시각 증거가 없음 | historical 캡처를 현재 증거로 쓰지 않고 60일 P1에서 접근성ㆍ시각 재검증 |

## 30ㆍ60ㆍ90일 합의안

### 30일

- train review 232건을 사람 검토하고 불일치 조정 절차와 담당자를 확정한다.
- 후보 0건 규칙의 추가 표본 또는 적용 불가 정책을 근거와 함께 정한다.

### 60일

- 민간 출처ㆍ직군 다양성 기준을 충족하거나 제품 적용 범위를 명시적으로 축소한다.
- 파일럿과 현재 UI 시각ㆍ접근성 검증을 수행한다.
- 위 개발 작업 뒤 규칙ㆍ매칭 버전을 동결하고 새 holdout 인계물을 만든다.

### 90일

- 동결 버전의 공공 90건ㆍ민간 90건을 독립ㆍ블라인드 이중 라벨링한다.
- 봉인 holdout은 `tools/evaluate.py --enforce-targets`로 한 번만 최종 평가한다.
- 실패 후 규칙을 바꾸면 같은 180건으로 다시 성능을 주장하지 않고 새 독립
  holdout을 구성한다.
- 현재 배포ㆍ클라이언트ㆍCIㆍ패키지 해시를 결합하고 기본 strict 명령이

## 오늘 커밋의 의미

오늘 변경은 v0.3의 규칙 품질, 개인정보 경계, 원격 최소 권한, 평가 무결성,
CIㆍ패키지 소스 동등성과 감사 가능성을 강화한다. 다음 항목은 여전히 v1.0 차단 사유다.

- 봉인 holdout 사람 라벨과 G1ㆍG2 최종 성능 없음
- 민간 train review 미완료와 0건 관찰 규칙 존재
- 민간 단일 출처ㆍ직군 편중
- Work24 접근과 법령 감사 Actions 성공 증거 미완료
- v1.0 릴리스 태그 없음

따라서 이 커밋을 “공정성 자동 판정 완성” 또는 “v1.0 성능 검증 완료”로 표현하지 않는다.
