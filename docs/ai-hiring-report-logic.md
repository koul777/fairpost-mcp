# AI 채용 보고서 기반 점검 로직

## 검토 자료

- 한국노동연구원(2024), `인공지능 채용 가이드라인(안) 개발`, 연구보고서 2024-02
- 한국산업인력공단(2023), `채용분야 인공지능(AI) 활용실태 및 공정성 확보방안 연구`

두 보고서의 권고는 법 위반을 직접 판정하는 근거가 아니라 AI 채용 운영을 검토하는 연구 근거 질문으로 사용한다. 완전히 자동화된 결정에 관한 `AI-001`만 개인정보 보호법 제37조의2에 연결한다.

## 해석 기준

- AI가 채용에 사용됐다는 사실만으로 법 위반을 단정하지 않는다. 해당 사실은 연구 근거 질문을 노출하는 조건이다.
- `AI-001`은 AI가 합격·불합격을 완전히 자동으로 결정한다고 명시한 경우에만 탐지한다. 권한 있는 사람이 독립적으로 최종 판단한다는 표현은 보호 예외로 처리한다.
- 인간 검토는 형식적 승인으로 보지 않는다. 결과에 영향을 줄 권한, 독립 판단 자료, 판단 근거와 조치 기록을 요구한다.
- 알고리즘 투명성은 소스코드 전체 공개보다 사용 단계, 주요 평가 항목, 결정 영향, 예상 결과와 관련 논리의 이해 가능한 설명에 초점을 둔다.
- 비동의자 모두에게 별도 전형을 제공해야 한다고 단정하지 않는다. 동의가 현실적으로 곤란한 경우의 이의신청 절차와 장애인·질환자의 편의 또는 대체 절차를 구분해 확인한다.
- 편향성 감사는 사용 전 입력·출력 편향을, 영향평가는 사용 후 집단별 결과를 본다. 모델이나 데이터가 중요하게 바뀌면 정기 주기 전이라도 재평가한다.
- 공급업체 도구를 사용해도 구인기업의 책임 검토를 생략하지 않는다. 계약에 데이터 출처, 모델 변경, 로그, 접근 통제와 파기 확인을 포함한다.
