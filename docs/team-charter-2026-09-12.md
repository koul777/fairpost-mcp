# FairPost 8시간 협업팀 운영 헌장

작성일: 2026-09-12 (KST)

## 운영 원칙

제가 팀장 겸 위원장으로서 작업 우선순위, 충돌 조정, 최종 승인 여부를 결정한다. 각 팀원은 자신의 영역에 대한 산출물과 검증 증거를 남기며, 다른 영역의 결론을 단독으로 덮어쓰지 않는다. Claude는 별도 외부 비판 검토자로 참여하고, 기존 Claude 세션에는 접근하지 않는다.

실제 에이전트 호출 가능 여부와 무관하게 아래 역할·산출물·승인 게이트를 고정한다. 내부 서브에이전트가 런타임 한도나 스레드 제한으로 호출되지 않는 경우에는 제가 해당 역할의 체크리스트를 순차 수행하고, 보고서에 호출 상태를 명시한다.

## 작업 흐름

1. Codex가 작업 카드를 만들고 담당 모델을 지정한다.
2. 담당자는 주장, 근거, 불확실성, 다음 조치를 분리해 남긴다.
3. Feynman이 테스트·재현성을 확인하고 Darwin이 출처 매핑을 확인한다.
4. Rawls가 사람 승인이나 공정성 게이트가 필요한지를 판정한다.
5. Claude가 독립적으로 누락과 과장을 공격 검토한다.
6. Codex가 충돌을 조정하고, Cicero가 결정과 blocker를 문서화한다.

## 의사결정 게이트

- `resolve`는 같은 패킷의 `edit_requested` 또는 `escalate`를 가리켜야 한다.
- 원문 공고·지원자 식별자·연락처는 패킷에 저장하지 않는다.
- 2026 NCS 자료는 공식 게시물·첨부 존재까지 확인했지만 첨부 본문/페이지 인용 전에는 제어 규칙의 근거로 매핑하지 않는다.
- 961개 자동 테스트 통과는 강한 회귀 증거지만, human holdout 라벨, G1/G2, 민간 코퍼스 다양성, Work24 접근, 현재 배포·태그 증거를 대체하지 않는다.
