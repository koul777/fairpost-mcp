# 민간 채용 출처 운영 기준

외부 수집 응답은 기본적으로 건당 32 MiB까지만 읽는다. 비정상적으로 큰 응답은
재시도하지 않고 중단하며, 검토 후 필요할 때만 `FAIRPOST_MAX_DOWNLOAD_BYTES`를
양의 정수 바이트 값으로 설정해 한도를 조정한다. URL은 인증정보와 fragment가 없는
HTTPS만 허용하고 XML 응답은 외부 엔터티를 해석하지 않는다.

검토일: 2026-08-04

## 현재 연결

### 진천군 일자리 구인정보

- 제공: 공공데이터포털, 충청북도 진천군
- 원천 규모: 38,700행
- 사용 범위: 최신 접수일 우선 3,000건
- 포함 정보: 채용제목, 고용형태, 급여, 학력, 경력, 성별, 우대조건,
  복리후생, 근무시간, 직무내용
- 처리: 회사명ㆍ이메일ㆍ전화번호 비식별화, 주소 열 제외
- 결과: 학습 2,100건, 봉인 홀드아웃 900건
- 수집기: `--source jincheon-jobs`

### 한국노인인력개발원 노인 구인정보

- 공식 목록 API와 상세 API를 모두 구현
- 상세 응답의 `detCnts`와 `etcItm`을 학습 대상으로 사용
- 담당자명ㆍ연락처ㆍ상세주소는 제외
- 별도 활용신청 후 `.env`의 `SENIOR_JOB_SERVICE_AUTH_KEY`에 키 입력
- 수집기: `--source senior-job`

## 승인 후 연결 가능한 출처

### 고용24

목록ㆍ상세 본문 수집기가 구현되어 있습니다. 현재 키는 채용정보
엔드포인트에서 개인회원 사용 불가 오류를 반환하므로 코퍼스에서
제외합니다. 2026-08-04 `display=1` 최소 목록 호출에서도 같은 API 업무 오류를
재현했으며 파일은 생성되지 않았습니다.

### 잡아바 Open API

공식 API는 인증키 승인 후 사용할 수 있지만 제공 필드는 회사명, 제목,
급여, 고용형태, 경력, 학력, 모집인원과 상세 URL 중심입니다. 공고 본문이
없으므로 단독으로는 표현 규칙 학습 자료가 아니라 메타데이터 보조
자료로만 취급합니다.

### 사람인 Open API

공식 API와 승인 절차가 있으나 목록 메타데이터 중심입니다. 사용 시
사람인 출처 표기 조건을 지켜야 하며, 연결 URL의 본문을 별도 허락 없이
크롤링하지 않습니다.

## 열람 전용 출처

잡코리아 신입ㆍ공채 페이지와 매칭뱅크는 최신 민간 공고의 대표 사례를
사람이 비교 검토하는 데 사용할 수 있습니다. 공개 화면을 자동 대량수집,
재배포 또는 학습 저장하는 기능은 별도 이용허락이 확인되기 전까지
구현하지 않습니다.
