# FairPost 홍보·시연 영상 콘티

상태: 최종 영상 제작·프레임 검수·사용자 재생 확인 완료
작성일: 2026-08-30  
참고 영상: `KakaoTalk_20260830_203901053.mp4`

## 제작 원칙

- 참고 영상의 넓은 여백, 짙은 네이비, 시안·오렌지 포인트, 빠른 선형 전환을
  시각 언어로만 참고한다.
- 핵심 내용은 합성 모션그래픽이 아니라 실제 배포된 FairPost UI의 사용 흐름으로
  보여 준다.
- 참고 영상의 음원을 복사하지 않는다. 필요한 경우 직접 만든 짧은 클릭·전환
  효과음만 사용한다.
- 결과를 “공정성 판정”으로 표현하지 않고 “수정·확인 메모”로 표현한다.

- 본편: 1920×1080, 30fps, H.264 MP4, 24.23초

- 자막: 하단 중앙, 짙은 네이비 배경, 흰색 30px

- 최종 파일:
  - `docs/assets/fairpost-promo.mp4`
  - `docs/assets/fairpost-promo.gif`

GitHub README 최상단에는 GIF 미리보기를 넣고, 클릭하면 MP4가 열리게 한다.
GitHub README의 인라인 MP4 재생 지원이 일관되지 않기 때문에 이 방식을 사용한다.

## 촬영 데이터

씬 1과 2는 웹 앱에 내장된 샘플 공고를 사용한다. 실제 개인정보나 기업의
공고문은 사용하지 않는다. 결과 카드의 구체적 문구와 건수는 촬영 당일 운영
배포에서 생성된 실제 값을 그대로 사용하며, 대본에 고정 숫자를 넣지 않는다.
