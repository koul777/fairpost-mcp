# 법령 범위와 규칙 연결표

기준일: 2026-07-26

이 문서는 PRD 부록 A의 조항 성격을 검수된 공식 조문 스냅샷과 런타임
규칙에 연결한다. 조문을 보관하는 것과 문구 탐지 규칙을 만드는 것은
구분한다. 공고문에 해당 표현이 없을 수 있는 고지 의무는 부재 슬롯과
질문 카드로 다룬다.

## 확인된 범위 한계

PRD는 「장애인고용촉진 및 직업재활법」에서 정당한 편의 제공도
살펴보도록 지시한다. 공식 현행 제5조는 장애인의 능력을 정당하게
평가할 책임과 채용상 차별 금지를 규정하지만, 채용 전형의 정당한 편의
신청 절차를 상세히 규정하지 않는다.

따라서 FairPost는 이 내용을 제5조의 법적 의무로 확대 해석하지 않는다.
현재는 `Q-PROC-007`에서 능력중심 채용 가이드에 근거한 검토 질문으로만
제시한다. 별도 장애인 차별금지 법률을 법령 근거로 추가하려면 다음
절차가 필요하다.

1. PRD 법령 범위 변경 승인
2. 국가법령정보센터 공식 조문ㆍ시행일 수집
3. 사람의 적용 범위 검수
4. 새 규칙의 홀드아웃 회귀 평가

## 변경 통제

`core.loader.REQUIRED_STATUTE_ARTICLES`는 위 검수 조문이 스냅샷에서
빠지면 로딩을 거부한다. 공식 원문 감사 보고서는 변경 조문별
`rule_ids`와 전체 `affected_rule_ids`를 기록한다. 변경 PR은 자동
병합하지 않는다.
