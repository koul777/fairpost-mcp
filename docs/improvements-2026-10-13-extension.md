## 확인한 문제와 변경

- 제목 장식을 지우는 정규식이 긴 공백의 각 위치에서 줄 끝까지 다시 탐색했다.
  Python·JavaScript의 같은 정규식을 수정해 불필요한 반복 탐색을 줄였다.
- 한 탭에서 역할 기록을 삭제한 뒤 다른 탭에서 기록하면 삭제한 이력이 되살아났다.
  저장 직전에 같은 패킷이 남아 있는지 확인하고, 삭제되었거나 새로 생성된 패킷이면
  기록을 중단하면서 작성 중인 메모를 보존한다.
- 브라우저 저장소의 삭제가 실패해도 화면에서 성공한 것처럼 사라지던 동작을 고쳤다.
  기록과 메모를 유지하고 실패를 알린다. 미반영 줄 수정안도 기존 삭제 확인에 포함한다.
  이전 v1 형식을 읽은 기록은 전환 저장에 실패해도 저장된 기록으로 취급하고,
  삭제 후 이전 형식의 복사본이 남아 있는지도 확인한다. 전환 쓰기 실패와 이전 키
  제거 실패를 각각 독립 재현해 성공 오표시가 사라졌는지 확인했다.
- 로컬 답변 저장소의 잘못된 값을 문자열로 바꾸거나 조직 항목을 버리던 동작을 고쳤다.
  손상된 형식을 발견하면 읽기·저장·개별 삭제를 중단하며 원본 파일을 보존한다.
- 검토 패킷의 저장 키와 내부 ID가 다르면 읽기와 이벤트 추가를 거부한다.

규칙·슬롯·법령 데이터는 변경하지 않았다. 봉인 홀드아웃을 열지 않았으며,
학습 입력 비교 결과는 원문과 레코드 식별자를 제외한 집계로만 기록한다.
