# 책과 저장소 매핑

기준 원고: 「본문_AI시대 공정이란 무엇인가_1006_교정메모.pdf」(10월 교정본).
최종 갱신: 2026-10-09. 종전 2026-07-26 확인본 중심의 연결표를 새 교정본의 관련 지면과 대조해 갱신했다. 규칙 데이터나 규칙의 검토일은 변경하지 않았다.

이 문서는 **책의 관점과 제품의 연결**을 설명한다. 실행 규칙의 직접 근거 및 법령의 현재 효력·적용 여부를 새로 검증한 문서는 아니다. FairPost의 범위는 채용공고 검토이며, 책이 다루는 성과평가·보상·승진 전체를 분석하는 도구로 확대하지 않는다.

## 페이지를 읽는 방법

- **인쇄 쪽수**는 본문에 찍힌 번호, **PDF 페이지**는 파일 처음부터 센 1기반 순서다. 교정본은 펼침면 163페이지이므로 두 번호가 다르다.
- 아래는 원고 전체의 자동 변환표가 아니라, 추출 본문과 쪽수 표기를 직접 대조한 관련 지면이다. 펼침면 텍스트에는 다음 장의 표제가 함께 들어올 수 있다. 예를 들어 PDF 67의 126쪽 체크리스트는 2-2에 속하며, 옆의 2-3 표제와 혼동하지 않는다. PDF 135의 262쪽은 4-2, PDF 139의 270쪽은 4-3의 체크리스트다.
- 원고 전문과 추출물은 로컬 `tmp/book-review/`에만 보관한다. 아래 요약은 원문을 재배포하기 위한 것이 아니다.

## 책의 취지와 제품 경계

| 책 위치 | 인쇄 쪽수 | PDF 페이지 | 확인한 취지와 제품 연결 |
|---|---:|---:|---|
| 들어가며 | 2~7 | 5~7 | 분배·절차·대인·정보의 네 물음을 함께 다룬다. 기본 화면에서도 의미와 관련 질문을 읽을 수 있게 하되 합산 점수로 바꾸지 않는다. |
| 들어가며 | 10~13 | 9~10 | 기준, 설명, 문의와 사람이 다시 검토할 통로를 미리 설계한다. 문구 수정에서 끝내지 않고 확인 근거와 다음 행동을 기록한다. |
| 마무리하며 | 298~299 | 153 | 인간 개입에는 권한·시간·정보·책임이 필요하다. 답변 입력이나 체크 완료를 실질적 검증 완료로 취급하지 않는다. |
| 마무리하며 · 부록 소개 | 302~303 | 155 | 채용공고의 법규·공정성 관점에서 놓친 지점과 조직이 답할 질문을 제시한다. 공정성 점수와 최종 판정은 하지 않는다. |

## 채용공고 질문 연결

다음 ID는 `data/rules/questions.yaml`에 존재하는 관련 질문의 예다. 책의 문장을 그대로 규칙화했다거나 책의 해당 쪽수가 각 질문의 직접 연구·법률 근거라는 뜻은 아니다. 질문별 발동 조건과 `basis`는 기존 데이터를 따른다.

| 책의 관점 연결 | 인쇄 쪽수 | PDF 페이지 | 공고 검토에서 이어지는 질문 예 |
|---|---:|---:|---|
| 1부 1-1 · 출발선, 평등과 형평 | 26~29 | 17~18 | 요건과 지원 기회를 검토하는 `Q-DIST-001`, `Q-DIST-002`, `Q-DIST-003`, `Q-DIST-004`, `Q-DIST-005`, `Q-DIST-006` |
| 1부 1-5 · 기록, 이의와 인간 감독 | 84~85 | 46 | 책임과 근거를 남기는 `Q-PROC-010`, 채용 이후 확인할 운영 질문 `Q-PROC-013` |
| 2부 2-1 · 과정의 신뢰, 참여와 수정 | 100~101, 108~109 | 54, 58 | 단계·기준·일정·변경 고지: `Q-PROC-001`, `Q-PROC-002`, `Q-PROC-003`, `Q-PROC-009` |
| 2부 2-2 · AI 채용 체크리스트 | 126 | 67 | 인간 재검토 `Q-PROC-004`, 책임과 개입 `Q-PROC-010`, 피드백·설명 `Q-INFO-008`, `Q-INFO-009` |
| 3부 3-1 · 존중과 대우 | 176~177, 184~185 | 92, 96 | 표현과 응대 원칙: `Q-INTER-001`, `Q-INTER-002`, `Q-INTER-005`, `Q-INTER-006`, `Q-INTER-007` |
| 3부 3-3 · 지원자 목소리, 인간 접점과 고지 | 202~203 | 105 | 설명·소명 `Q-INTER-003`, 비언어 분석 `Q-INTER-004`, 문의와 결과 안내 `Q-INFO-001`, `Q-INFO-002`, `Q-INFO-003`, AI 사용 확인 `Q-INFO-005` |
| 4부 4-1 · 정보비대칭과 이해 가능성 | 242~243, 252~253 | 125, 130 | 안내의 구체성·접근성: `Q-INFO-003`, `Q-INFO-004`, `Q-INFO-006`, `Q-INFO-007` |
| 4부 4-2 · 학습자료 편향과 외부 검증 | 262 | 135 | 데이터 대표성 `Q-DIST-008`, 운영 감사 `Q-PROC-014` |
| 4부 4-3 · 대리변수, 조직에 맞는 자료와 재검토 | 268~270 | 138~139 | 대리변수·직무 타당성: `Q-DIST-009`, `Q-DIST-010`, `Q-DIST-011` |

1부 1-5와 3부 3-1 등의 논의를 채용공고 질문에 잇는 것은 제품 설계상의 적용이다. 보상 결정, 실제 면접, 학습자료 감사나 채용 후 평가를 프로그램이 수행한다는 뜻이 아니다. 특히 실제 편향·응대·재검토의 효과는 공고문만으로 확인할 수 없다.

## 직접 근거와 책 연결을 구분한다

| 구분 | 저장 위치·필드 | 읽는 원칙 |
|---|---|---|
| 법령 관련 표현 규칙 | `data/rules/law.yaml`의 `basis`, `data/statutes/*.yaml` | 법령명·조문·스냅샷 날짜를 직접 근거로 읽는다. 책과 연결되었다는 이유만으로 법 위반이나 적법을 확정하지 않는다. |
| 연구·가이드·기관 자료 | `data/rules/questions.yaml`의 `basis` | 자료명·발행기관·연도·자료 내 위치·URL·확인일 등 실제 저장된 메타데이터를 따른다. 자료의 쪽수를 이 책의 쪽수로 바꾸지 않는다. |
| 합의 기반 운영 질문 | 같은 파일의 `basis.type: consensus` | 운영상 검토 질문이다. 법적 의무나 실증적으로 검증된 판단으로 승격하지 않는다. |
| 책 관점 연결 또는 외부 자료 위치 | 각 규칙의 `book_ref` | 이름과 달리 값에 책 장절과 외부 자료가 혼재한다. 값과 `basis`의 자료 정체성을 함께 확인한다. |

실제 혼동 사례:

- `Q-PROC-004`의 `book_ref: 제6장 결론 270-272쪽`은 `basis.title`의 「채용분야 인공지능(AI) 활용실태 및 공정성 확보방안 연구」 위치다. 이 책의 270~272쪽을 가리키지 않는다. 책 연결은 위 표의 인쇄 126쪽/PDF 67로 별도 제시한다.
- `Q-INFO-009`의 제5장 211~218쪽은 「인공지능 채용 가이드라인(안) 개발」의 위치다. `Q-PROC-010`, `Q-INTER-003`, `Q-INTER-004`, `Q-DIST-009`에도 이 자료의 위치가 사용된다.
- `Q-INFO-010`의 NCS 자료와 공감채용 가이드 PDF 14쪽은 외부 자료 연결이다. 외부 가이드의 파일 페이지 대조와 한계는 [능력중심 채용 가이드 적용 맵](ability-based-hiring-guide-map.md)을 함께 확인한다.
- `Q-INFO-014`처럼 `basis.type`은 `research`지만 제목은 법령인 항목도 있다. 타입 이름만으로 출처를 재분류하지 않고 제목·조문·URL을 함께 읽는다. 이번 문서 갱신은 그 법령의 현행성 검증을 포함하지 않는다.

화면의 출처 표시는 “책 연결”, “근거 자료와 위치”를 구분하는 것이 바람직하다. 데이터의 `book_ref`나 기존 검토일을 이번 확인일로 일괄 변경하지 않는다.

## 저장소 산출물

| 역할 | 경로 |
|---|---|
| 관련 표현의 법령 규칙 | `data/rules/law.yaml` |

| 공고에서 찾는 안내 항목 | `data/slots.yaml` |
| 법령 스냅샷 | `data/statutes/*.yaml` |
| 제외·유보한 표현 | `data/rules/rejected.yaml` |
| 기관 자체 체크리스트 예시 | `data/local_rules.example.yaml` |
| CLI 실행 진입점 | `cli/main.py` |
| 로컬 웹 런타임 | `mcp_server/local_runtime.py` |
| MCP 선택 연동 | `mcp_server/server.py` |
| 독자용 화면과 브라우저 엔진 | `web/index.html`, `web/app.js`, `web/engine.js` |
| 외부 가이드 적용 경계 | [능력중심 채용 가이드 적용 맵](ability-based-hiring-guide-map.md) |
| 이번 책 연결 설계와 수용 기준 | [책 부록 설계 검토](book-companion-design-2026-10-09.md) |

공고에 안내가 탐지되지 않았다는 결과는 실제 제도 부재의 증거가 아니다. 운영 질문의 답은 담당자가 확인한 사실·근거와 함께 기록하며, 답하지 못한 항목은 남은 확인사항으로 둔다. 기본 엔진의 외부 AI 없는 분석 기조와 채용공고 범위를 유지한다.
