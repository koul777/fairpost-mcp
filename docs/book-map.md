담습니다. `book_ref`는 각 규칙에서 해당 설명 위치를 연결합니다.

## 채용공고 질문 연결

| 원고 위치 | 공고 단계에서 확인할 관점 | 실행 규칙 |
|---|---|---|
| 1부 1-1ㆍ1-5 | 요건의 직무 관련성, 우대기준, 출발선과 다양한 잠재력 | `Q-DIST-001`~`008`, `Q-DIST-011` |
| 2부 2-1 | 기준의 일관성, 변경 고지, 수정 가능성 | `Q-PROC-001`~`003`, `Q-PROC-009` |
| 2부 2-2 | AI 평가 설명, 인간 재검토, 최종 책임, 구체적 피드백 | `Q-PROC-004`, `Q-PROC-010`, `Q-INFO-008`~`009` |
| 3부 3-3 | 지원자의 Voice, 인간 접점, 비언어 분석 고지 | `Q-INTER-003`~`004`, `Q-INFO-001`ㆍ`003` |
| 4부 4-1 | 이해 가능한 기본 정보와 정보비대칭 | `Q-INFO-002`~`007` |
| 4부 4-2ㆍ4-4 | 학습데이터 편향, 외부 검증, 배포 후 감사 | `Q-DIST-008` |
| 4부 4-3 | 대리변수, 조직 적합 데이터, 과거 합격자 복제 방지 | `Q-DIST-009`~`011` |

원고에 있는 운영 질문 중 공고문만으로 답을 확인할 수 없는 항목은 법 위반이나
부재로 판정하지 않는다. AI 사용 또는 관련 표현이 확인될 때 조직이 직접 답할
질문으로 제시한다.
