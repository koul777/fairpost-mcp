# 능력중심 채용 가이드 적용 맵

## 적용 원칙

두 가이드북은 법적 위반 여부를 판정하는 자료가 아니다. FairPost는 가이드의
체크리스트를 `question` 계층에만 사용한다. 법령 스냅샷을 근거로 하는 `law`
탐지와 분리하며, 점수ㆍ합격/불합격ㆍ공정/불공정 결론을 만들지 않는다.

## 제한

- 페이지 표시는 PDF의 표시 페이지가 아니라 파일 페이지 순서를 기준으로 한다.
- 가이드에 있다는 이유만으로 표현을 법 위반으로 분류하지 않는다.
- 질문에 대한 답과 최종 판단은 채용 조직과 담당자가 기록한다.
