# 능력중심 채용 가이드 적용 맵

## 적용 원칙

가이드북과 NCS 웹 자료는 법적 위반 여부를 판정하는 자료가 아니다. FairPost는 가이드의
체크리스트를 `question` 계층에만 사용한다. 법령 스냅샷을 근거로 하는 `law`
탐지와 분리하며, 점수ㆍ합격/불합격ㆍ공정/불공정 결론을 만들지 않는다.

`Q-INFO-011`은 단순한 `제출서류` 표제가 아니라 졸업ㆍ성적ㆍ경력ㆍ자격 등
구체적인 증빙서류 표현에서만 발동한다. 명시적으로 제출이 불필요하거나
제출하지 않는다고 안내한 문맥은 제외한다.

`Q-INFO-012`는 신입ㆍ경력 같은 넓은 단어 동시출현을 사용하지 않는다.
`근무분야`의 같은 목록행에 비연구직과 연구직이 함께 있고, 600자 안에
구체적인 학력ㆍ전공ㆍ학위 단서가 있으며 5,000자 안에 지원서 양식 단서가
있는 경우에만 사람 검토 질문을 제시한다. 이는 지원서의 실제 조건부
필드를 판정하는 규칙이 아니다.

## 제공 HWP의 사용 결정

`직원 채용시 고려해야 할 법률적 문제들.hwp`는 채용공고ㆍ수습ㆍ계약ㆍ기록
등의 쟁점을 찾는 참고자료로만 분류했다. 본문이 2001~2003년 법령ㆍ사례를
주로 인용하고 발행 주체와 작성일을 확인할 수 없어, 현행 법률 규칙이나
질문 카드의 직접 근거로 사용하지 않았다.

전체 조사 근거와 한계, 사람 검토 질문은
`docs/ncs-fairness-research-bundle.json`에 별도로 보존한다.

## 제한

- 페이지 표시는 PDF의 표시 페이지가 아니라 파일 페이지 순서를 기준으로 한다.
- 가이드에 있다는 이유만으로 표현을 법 위반으로 분류하지 않는다.
- 질문에 대한 답과 최종 판단은 채용 조직과 담당자가 기록한다.
