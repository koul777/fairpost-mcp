# 민간 코퍼스 다양성 게이트

현재 공개 민간 코퍼스는 진천군 공개 구인정보 한 출처에 의존한다. 이
집계에서 관찰한 발동률이나 앞으로 측정할 성능을 민간 채용시장 전체로
일반화하지 않는다.

`tools/audit_corpus_diversity.py`는 공고 원문을 읽지 않고 기존 익명 코퍼스
요약의 출처와 직군 비율만 검사한다.

```powershell
python tools\audit_corpus_diversity.py
```

초기 목표는 다음과 같다.

- 허가된 민간 출처 2개 이상
- 단일 출처 비중 70% 이하
- 사무ㆍ기술ㆍ연구 직군 합계 35% 이상
- 기술ㆍ연구 직군 합계 10% 이상
- train/holdout 원문 해시 중복 0
- 원문 미배포와 비식별화 선언 유지

현재 기준선은 의도적으로 `alert`다. 이 경보를 없애려고 기존 출처를 여러
이름으로 나누면 안 된다. 독립 수집 경로와 이용 권한을 가진 새 출처가
들어온 뒤 `--enforce`를 CI 또는 릴리스 게이트에 추가한다.
