# NCS 공정채용 최신 자료 대비 개선 분석

조사일: 2026-07-29

2026-07-29에 공식 자료실 첫 페이지를 다시 확인했다. 공정채용 교육자료의
최신 공지 항목은 수정일 2025-07-29인 `2025년 공공기관 공정채용
모니터링 주요 위반 사례`이고, 공정채용 가이드북의 최신 공지 항목은
수정일 2025-04-23인 `공정채용 가이드북(인사담당자용)`이었다. 따라서
이번 비교에 사용한 두 자료보다 최근인 2026년판 가이드ㆍ모니터링 자료는
해당 공식 목록에서 확인되지 않았다.

## 조사 질문과 범위

현재 NCS 공정채용 누리집과 최신 공식 자료가 제시하는 통제 중 FairPost가
아직 직접 확인하지 않는 것은 무엇인지, 그중 채용공고 원문만으로 좁고
결정적으로 발동할 수 있는 항목은 무엇인지 조사했다.

한국산업인력공단의 공개 자료만 사용했다. 지원자 개인정보, 실제 채용결과,
기관 식별자와 봉인 평가자료는 열거나 기록하지 않았다. NCS 자료는 실무
지침이며 자동 법률판정 근거로 사용하지 않았다.

## 구현한 개선

`Q-INFO-010`의 광범위한 `제출서류` 트리거를 제거하고 지원서·응시원서·
개인정보 수집 문맥에 집중시켰다. 새 `Q-INFO-011`은 증빙서류, 입증자료,
졸업증명서, 성적증명서, 경력증명서, 자격·면허 증명, 어학 성적증명서,
주민등록등본처럼 구체적인 증빙 표현에서만 발동한다.

질문은 다음 세 가지를 사람에게 확인하도록 한다.

1. 서류전형 합격 이후 등 적절한 시점에 필요한 자료만 최소 제출하는지
2. 수집금지 또는 직무와 무관한 편견정보를 가리도록 안내하는지
3. 원본과 평가위원 제공본의 접근·마스킹·보관·폐기 책임을 구분하는지

`증빙서류 제출 불필요`, `졸업증명서는 제출하지 않습니다`처럼 명시적인
비요구 문맥은 제외했다. 결과는 위반 판정이나 등급이 아니라 근거와 원문
위치를 포함한 질문 카드다.

웹 질문 카드와 복사 보고서에는 이미 결과 JSON에 포함되어 있던
출판기관ㆍ발행연도ㆍ인용 쪽수ㆍ웹 확인일을 표시하도록 보완했다. 공식
자료가 갱신될 수 있다는 점을 사용자가 결과 화면에서 직접 확인할 수 있게
하고, `Q-INFO-011`의 PDF 7쪽 인용을 구조화된 참조 필드로 제공한다.

복수 직렬 후보는 공개 train 2,520건에서 넓은 단어 동시출현 111건을
목적표본 검토한 뒤 좁혔다. `신입`ㆍ`경력`, 기관명 속 `연구소`, 설명문
속 `기술` 같은 단서는 오발동이 많아 사용하지 않았다. `Q-INFO-012`는
`근무분야` 바로 다음 한 목록행에 비연구직군과 연구직군이 함께 있는
구조를 원문 근거로 삼는다. 학력ㆍ전공ㆍ학위 단서는 600자, 지원서 단서는
5,000자 안에 있어야 하며 직렬별 별도 양식이나 조건부 항목을 명시한
문맥은 제외한다. `학력사항: 무관`, `최종 학력: 무관`,
`졸업증명서: 해당 없음`처럼 정보 요구가 아님을 같은 줄이나 바로 다음
표 셀 줄에서 명시한 단서도 발동 근거로 쓰지 않는다. 결과는 공통양식 사용
여부나 위반을 판정하지 않고,
직렬별 필드ㆍ자격ㆍ제출서류 분리를 사람이 확인하게 한다.

`Q-DIST-014`는 공인어학 시험명과 최소점수ㆍ등급, 600자 이내의
지원자격 문맥을 모두 요구한다. 해외영업ㆍ국제협력처럼 외국어 사용
업무가 명시되어도 요구 수준의 비례성은 별도로 확인할 수 있으므로 자동
면제하지 않는다. 결과는 실제 업무 장면과 요구 수준의 연결을 사람이
확인하게 한다. 공개 train에서는 공공 3건, 민간 0건이었다.

연구개발목적기관 예외는 별도 질문으로 만들지 않았다. 공개 train
중복제거 2,310건에서 `연구개발목적기관`, `주무부처`,
`학위취득기관`, `추천서`의 정확한 후보가 모두 0건이었고, 학교명 143건은
모두 미기재ㆍ기재금지 같은 보호 문맥이었다. 넓은 `연구기관`이나
`학교명` 단독 트리거는 역방향 오발동 위험이 커 실제 양성을 확보한 뒤
구조화한다.

## 학습 분할 영향

봉인 자료를 사용하지 않고 `.corpus-prd/train` 420건만 익명 집계했다.

| 질문 | 변경 전 발동 | 변경 후 발동 |
|---|---:|---:|
| `Q-INFO-010` 지원서 최소수집 | 186건, 44.3% | 137건, 32.6% |
| `Q-INFO-011` 증빙서류 단계·마스킹 | 없음 | 58건, 13.8% |
| `Q-INFO-012` 복수 직렬 양식 분리 | 없음 | 2건, 0.5% |
| `Q-DIST-014` 공인어학 최소점수 직무관련성 | 없음 | 3건, 0.7% |

새 질문 58건 중 다수는 기존 지원서 질문과 겹치지만 검토 대상이 다르다.
단순 `제출서류` 표제만 있던 49건은 기존 지원서 질문에서 빠져 의미
정확도가 개선됐다. 이 NCS 변경 직후 전체 질문 인스턴스는 5,659개에서
5,668개로 9개 증가했고, 복수 직렬ㆍ공인어학 질문까지 포함한 당시 전체는
5,673개였다. 이후 민간 공정성ㆍ면접 운영ㆍAI 감사 질문과 관련질문 연결이
추가된 2026-08-30 현재 전체는 6,806개이며 최신 집계는
`reports/question_relevance_audit.json`에서 확인한다.

## 반대 근거와 한계

- 최신 모니터링 자료는 공공기관 블라인드 채용을 전제로 한다. 민간 공고에
  같은 예외체계를 일률 적용할 수 없다.
- 학력·전공·외국어·추천서 등은 기관유형, 직무관련성, 사회형평 목적에 따라
  예외적으로 수집될 수 있다.
- 증빙서류가 언급되었다는 사실만으로 제출 시점, 마스킹 또는 평가위원
  차단의 실제 이행 여부를 확인할 수 없다.
- 여러 직렬의 분리 여부는 표와 제목의 계층, 직렬별 지원서 연결관계를
  이해해야 한다. 현재 규칙은 같은 목록행과 제한된 문맥으로 사람 검토
  후보만 고르며, 첨부 또는 온라인 양식의 실제 조건부 동작은 확인하지
  못한다.

## 다음 사람 검토 질문

- 증빙서류의 제출 시점과 제출 대상은 자격 확인 필요성에 맞게 구분되어
  있는가?
- 원본에서 가릴 정보와 평가위원에게 전달할 정보를 누가 검수하는가?
- 여러 직렬을 함께 모집할 때 한 직렬의 학력·전공 요건이 다른 직렬의
  지원서에 섞이지 않는가?
- 예외적으로 수집하는 정보의 종류·범위·사유와 근거가 지원자에게
  공개되어 있는가?
