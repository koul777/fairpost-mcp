# 채용공고 개선 도우미 보완 계획 · 2026-10-10

책 부록(인쇄 302~303쪽, PDF 155)이 설명하는 프로그램의 역할은 채용공고문을 입력하면 관련 법규와 공정성의 관점에서 점검할 지점과 조직이 답할 질문을 제시하고, 점수나 최종 판정 없이 사람이 공고를 고쳐 가도록 돕는 것이다. 이번 보완은 책의 장절·체크리스트를 프로그램에 옮기는 작업이 아니라, 독자가 **접속 → 점검 → 고치기 → 다시 보기**를 막힘없이 하도록 공고 개선 흐름을 채우는 작업이다.

## 현재 빈틈

| 단계 | 현재 | 빈틈 |
|---|---|---|
| 접속 | 책은 QR 주소로 접속하도록 안내한다. | 2026-10-10 확인 시 공개 웹 `fairmcp.vercel.app/web/`에 10월 9일 보완(네 관점 질문·검토 기록)이 없다. 교정본 QR에는 접속 오류 메모가 있다. README 첫 경로는 Python 설치다. |
| 표현 고치기 | 다시 볼 표현과 대안 지침을 보여 준다. | 대안은 “~로 대체”, “~을 명시” 같은 지침이고, 화면에는 “공고문에서 이 부분 선택” 버튼만 있다. |
| 빠진 안내 채우기 | 공고문에서 찾지 못한 안내 이름을 보여 준다. | 공고에 넣을 예시 문장이 없다. |
| 결과 정리 | 표시 항목 단위 수정 전후 비교와 메모 복사가 있다. | 바뀐 문장 목록과 개선된 공고문 자체를 가져가는 출력이 없다. |

## 지킬 조건

- 규칙 데이터는 바꾸지 않는다. 현재 브랜치(6ff67c6)의 규칙셋은 `2026.07-local-v5-nfkc-whitespace-zero-width-regex-source-offset-0fa75d41155c`이며, 로드맵이 2026-10-04에 선언한 동결 후보 `…da8f450a87f4`와 이미 다르다(6ff67c6에서 질문·슬롯 데이터 변경). 이 차이는 이번 작업 범위 밖의 기존 상태로 기록한다. `data/rules/questions.yaml`, `data/rules/law.yaml`, `data/slots.yaml`, `core/engine.py`, `web/engine.js`, `web/data.js`의 SHA-256을 전후로 일치시킨다. 예시 문장은 규칙셋 해시에 들어가지 않는 별도 파일에 둔다.
- 점수·등급·통과·완료 판정을 만들지 않는다. 기본 검사는 외부 AI를 호출하지 않으며 공고문을 자동으로 외부에 보내지 않는다.
- 자동 고쳐쓰기를 하지 않는다. 예시 문장은 빈칸(○○)을 조직의 실제 사실로 채우는 출발점이며, 표현 수정은 사람이 쓰고 반영한다.
- 공개 배포·push는 별도 승인 뒤에 한다.
