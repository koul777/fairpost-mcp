# Claude 협의 8시간 실행 계획

계획일: 2026-09-12 (KST)

이 계획은 MCP가 제공한 새 Claude CLI 세션과 현재 저장소를 읽기 전용으로 검토해 만든 실행 순서다. 기존 Claude 세션은 조회하거나 메시지를 보내지 않았다. 실행 중에는 각 블록의 통과 조건과 산출물을 세션 로그에 남긴다.

## 실행 블록

| 블록 | 시간 | 목표와 산출물 | 통과 기준 |
|---|---:|---|---|
| 1. 기준선 고정 | 45분 | `git status`, diff·최근 커밋·테스트 기준선 확인. 설명되지 않는 변경을 별도 이슈로 기록 | 현재 변경이 역할 검토·NCS 근거·브라우저 흐름과 대응되고 사용자 변경을 덮지 않음 |

## Claude가 지적한 핵심 위험과 대응

1. 자유 텍스트 `note`는 원문·지원자 정보를 다시 담을 수 있다. 고신뢰 직접식별 패턴은 거부하고, 의미 기반 완전 탐지는 약속하지 않으며 UI·문서 경고를 병행한다.
2. 하나의 손상된 패킷이 저장소 전체의 검증을 막을 수 있다. `save`·대상 패킷 `get`·`append`·`purge`는 top-level 구조만 읽은 뒤 새로 쓰거나 요청한 패킷만 검증한다. 손상 패킷은 자동 삭제하지 않는다.
3. 산인공 2026 가이드북은 공식 게시물 메타데이터와 첨부 존재까지 확인했으나 첨부 본문은 아직 파싱하지 않았다. 본문 문구를 확인했다고 표현하지 않는다.

## 사람 승인 없이는 해제하지 않는 보류

- 봉인 holdout 공공·민간 사람 라벨과 G1/G2 품질 게이트
- 민간 출처 다양화와 Work24 원천 접근
- 2026 가이드 첨부 바이너리의 실제 다운로드·본문 파싱·페이지 인용
- 실제 GitHub CI·배포 증거 실행
- 인증·조직 권한·보존·삭제·암호화가 확정되지 않은 원격 검토 공유

## 실행 메모

실제 실행은 이 계획을 기계적 체크리스트로만 따르지 않고, 각 블록에서 발견된 위험을 다음 블록의 테스트·문서 산출물로 연결한다. Claude의 계획 자체는 외부 사실의 증거가 아니며, NCS 사실은 [`ncs-2026-guide-evidence.md`](../reports/ncs-2026-guide-evidence.md)의 공식 출처 기록으로 따로 추적한다.
