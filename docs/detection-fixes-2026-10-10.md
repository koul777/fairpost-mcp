## 과제 A — 보호 문구가 다른 항목의 위법 요구를 가림

보호 동사는 이제 그 후보가 들어 있는 절 안에서만 보호로 본다. 절 경계는 `.!?;`, 어간 뒤의
연결 어미(`되나`, `지만`, `(으)며`, `…고`, `…나`)와 쉼표다. 다만 조건절 뒤의 쉼표와 명사
나열 사이의 쉼표는 경계로 보지 않는다. 고객·공고·나이·며칠처럼 같은 글자로 시작하는 낱말은
절을 나누지 않는다. `미기재 시`, `기재하지 않으면` 뒤에 불이익·탈락·제외·부적합·감점이
오면 요구로 본다. SCHOOL-001의 `exclude`는 HEALTH-001과 같은 형식으로 바꿨다.

| 문장 | 수정 전 | 수정 후 |
|---|---|---|
| 사진은 기재하지 않아도 되나, 부모 직업은 반드시 기재해야 합니다. | 없음 | FAMILY-001 |
| 주민등록번호는 수집하지 않으며 지원서에 부모 직업을 기재하십시오. | 없음 | FAMILY-001 |
| 출신학교는 기재하지 마시고, 부모의 학력을 기재해 주세요. | 없음 | SCHOOL-001 |
| 부모 직업 미기재 시 탈락처리 | 없음 | FAMILY-001 |
| 부모 직업을 기재하지 않으면 서류전형에서 불이익이 있습니다. | 없음 | FAMILY-001 |
| 형제자매의 학력을 기재하지 않은 지원서는 평가대상에서 제외합니다. | 없음 | SCHOOL-001 (가족 학력 규칙) |
| 지원자격: 신체 조건 키 175cm 이상, 출신학교 기재 금지 | BODY-001 | BODY-001 + Q-DIST-007 |
| 가족 같은 분위기, 이력서에 사진 기재 불필요 | 없음 | Q-INTER-002 |
| 주민등록번호 뒷자리는 기재하지 마시고 가족관계증명서를 제출하세요. | 없음 | Q-INFO-011 |
| 부모 직업은 기재하지 마세요 / 출신학교는 기재하지 않습니다 | 표시 안 함 | 표시 안 함 |
| 신체 조건과 무관하게 채용합니다 | Q-DIST-007 | 표시 안 함 |

## 과제 B — '담당업무' 제목이 공고 나머지를 삼킴

업무 구간은 담당업무 제목 바로 아래의 목록으로 한정한다. 빈 줄, 장식 제목, 같은 번호 체계의
다음 제목, 글머리 목록 뒤의 짧은 제목에서 구간이 끝난다. 제목 장식에
`●○◆◇▶▷□◎※【】<>`를 더했다. 맨 `인터뷰`·`서류접수`·`서류 검토`·`서류 리뷰`는 다음 경우에만
전형 단계로 본다.

- 전형절차·일정 섹션 안에 있을 때
- →, N차, 단계, 전형, 최종 합격 옆에 있을 때
- 다른 명명된 전형과 함께 나올 때

예시 문장의 제목(평가 기준, 결과 안내, 이의제기 안내, 채용서류 반환ㆍ파기 안내, 인공지능
활용 안내)은 섹션 별칭으로 인정했다. 공문식 띄어 쓴 날짜(`2026. 8. 1.`)도 날짜로 읽는다.

| 사례 | 수정 전 | 수정 후 |
|---|---|---|
| 담당업무 뒤 ●전형절차·●근무조건·●접수기간·●문의 | 네 슬롯 모두 없음 | selection_stages·compensation·schedule·contact_point |
| 담당업무 뒤 "채용 안내 / 1차 AI 면접 실시 후 대면 면접" | ai_disclosure와 AI·면접 질문 없음 | ai_disclosure와 질문 복구 |
| 업무 구간으로 끝나는 공고 + 예시 문장 5종 | 5개 슬롯 계속 없음 | 모두 찾음 |
| 고객 인터뷰 / 민원 서류접수 / 계약 서류 검토 업무 | 전형 단계로 오인 | 전형 단계 아님 |
| 전형절차 / 1. 서류 리뷰 / 2. AI 영상면접 / 3. 최종 면접 | 못 찾음 | selection_stages·ai_disclosure |
| 채용 절차 / - 지원서 리뷰 / - 인터뷰 / - 최종 합격 | 못 찾음 | selection_stages |

회귀 테스트: `tests/test_heading_duty_regressions.py`, `tests/test_posting_templates.py`의
예시 문장 삽입 회귀

## 소유자 확인이 필요한 사항

1. 인계 문서는 `형제자매의 학력…`을 FAMILY-001로 적었다. 하지만 이 내용은 가족 학력 규칙인
   SCHOOL-001("직계 존비속 또는 형제자매의 학력 정보 요구")에 해당하므로 SCHOOL-001로 표시한다.
2. `신체 조건과 무관하게 채용합니다`는 이전에는 Q-DIST-007을 물었지만 이제는 표시하지 않는다.
3. 질문 규칙 두 개의 `exclude`가 아직 절을 넘어 적용된다.
   - Q-DIST-005의 `출신학교…{0,120}기재 금지`
   - Q-DIST-017의 `혼인 여부…{0,600}`
4. `core/engine.py`는 후보가 보호되어 기각된 연결 질문을 띄우지 않는다. 그래서
   `출신학교는 기재하지 마시고, 부모의 학력을 기재해 주세요.`에서는 SCHOOL-001만 뜨고
   Q-DIST-005는 뜨지 않는다.
5. 아직 표시가 맞지 않는 경계 사례가 있다.
   - `부모 직업 미기재 시 불이익 없음`은 여전히 FAMILY-001로 표시된다.
   - `신체 조건 무관, 단 키 175cm 이상 필수`는 BODY-001만 뜨고 연결 질문은 뜨지 않는다.
6. 템플릿 제목 별칭의 섹션 대응이 맞는지 확인이 필요하다.
   - 평가 기준, 인공지능 활용 안내 → 전형절차
   - 결과 안내 → 일정
   - 이의제기, 반환ㆍ파기 → 유의사항
7. 아직 처리하지 않은 탐지 동작이 있다.
   - `최종 면접`·`임원 면접`처럼 맨 `면접`이 들어간 이름은 selection_stages 인정 패턴이 아니다.
   - 글머리표 없이 이어 쓴 업무 줄은 여전히 뒤의 줄을 삼킨다.
   - 1588 번호나 `총무과`만 적힌 문의처는 연락 창구로 보지 않는다.
8. `91232bd` 이후 `결과는 이메일로 안내합니다`처럼 채용 단어가 없는 단독 문장은 결과 통지로
   보지 않는다. 비공개 코퍼스에서는 이 변경으로 result_notice가 바뀐 공고가 없었다.
   섹션 맥락으로 되살릴지는 위 사례와 함께 결정한다.
