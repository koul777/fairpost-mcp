# Claude MCP × Codex 재감리 기록

검토일: 2026-08-31
대상: FairPost/FairMCP v0.3 후보의 제품 취지 강화

## 감리 방법

- Claude Code 2.1.251의 프로젝트 MCP 신뢰와 서버 승인을 실제 대화형 절차로 완료했다.
- 초기 감리에서는 `fairpost-local`이 루프백 `http://127.0.0.1:8000/mcp`에서 네 도구로 연결된 상태를 확인했다. 이후 기본 별칭을 `fairpost`로 바꾸고 구조화 점검을 추가해 전체 5도구로 확장했다.
- Claude Opus 4.8이 합성 공고를 대상으로 `check_job_posting`과
  `next_review_question`을 실제 호출했다. 호출은 권한 거부 없이 끝났고 파일은
  수정하지 않았다.
- Codex와 독립 에이전트가 제품 경계, 코드 흐름, 보안ㆍ프라이버시를 별도로
  읽고 Claude의 관찰과 대조했다.

이 감리는 모델의 의견만으로 규칙을 승격하지 않는다. 실제 코드, 도구 출력,
원문 offset 회귀, 공개ㆍ민간 train 익명 집계를 함께 확인하고 사람 검토가 필요한
성능 주장은 계속 보류한다.

## 초기 Claude MCP 실제 호출 관찰

합성 입력에는 연령 암시, 출생연도 제한, 성별 우대, 건강ㆍ외모 표현과 불완전한
절차ㆍ정보 안내를 함께 넣었다.

- 호출 도구: `check_job_posting`, `next_review_question`
- finding ID: 0개
- 직접 문맥 질문: `Q-DIST-015`의 `남성 우대`, `Q-PROC-006`의 `우대`
- 누락 안내에 연결된 질문: `Q-DIST-001`, `Q-DIST-002`, `Q-PROC-002`,
  `Q-PROC-003`, `Q-INFO-001`~`Q-INFO-005`

`남성 우대`를 곧바로 법 위반 finding으로 만들지 않고 직무 본질성 또는 적극적
고용개선 근거를 묻는 `Q-DIST-015`로 보낸 것은 기존의 사람 검토 정책과
일치했다. 반면 `젊고`, `1995년 이후 출생자만`, `외모 단정한`은 기존 법령
표현 규칙의 명백한 어순ㆍ활용 변형인데도 finding 근거가 남지 않았다.

이에 `AGE-001`, `AGE-002`, `LOOK-001`에 세 변형을 최소 범위로 추가하고,
각 매칭 문구가 입력 원문의 정확한 offset을 가리키는 회귀 테스트를 고정했다.
공공 210건ㆍ민간 2,100건 train 익명 집계에서는 세 추가 변형으로 새 관찰 건수가
생기지 않았다. 따라서 이 변경은 합성 경계 회귀 근거이며 사람 정밀도 또는 시장
빈도 증거로 해석하지 않는다.

## 최종 Claude MCP 독립 감리

02:50 KST 이후 Claude Code 2.1.251을 읽기 전용 `plan` 모드로 다시 실행했다.
Claude는 로컬 `fairpost`의 `check_job_posting`,
`check_job_posting_structured`, `next_review_question`을 모두 실제 호출했고
파일 수정ㆍ셸ㆍ답변 저장ㆍ원격 MCP는 허용하지 않았다.

- 종료 코드 0, 17 turns, 169,863ms로 PASS했다. 전체 출력은 저장하지 않고 캡처된
  JSON의 SHA-256 `0f9812d6…7c14`만 감리 영수증으로 남겼다.
- `AGE-001 [16,18]`, `LOOK-001 [19,24]`, `SEX-001 [26,29]`,
  `AGE-002 [38,51]` 네 finding과 평문ㆍ구조화 21개 질문의 일치를 확인했다.
- 면책문 선행, `fairpost-structured-check-v1`, finding→질문→법령ㆍ문헌→원문
  offset 추적, 브라우저 답변의 사람 입력ㆍ메모리 전용ㆍ재실행/지우기 초기화를
  코드와 도구 출력으로 대조했다.
- Claude는 설명 중 일반 원격과 Claude 호환 원격을 모두 3도구라고 표현했지만,
  실제 계약은 일반 원격 3도구와 Claude 호환 평문 1도구다. 이 차이는 배포 검증기
  v3의 실제 목록ㆍ호출 결과로 교정해 `reports/mcp_client_audit.json`에 함께
  기록했다.
- Claude가 남긴 잔여 위험은 당시 증거 파일이 아직 커밋 전이었다는 점, 원격
  경계는 Claude가 실호출하지 않고 소스로 확인했다는 점, 법령 스냅샷 이후 개정과
  전체 21질문 저장 순회는 감리 범위 밖이라는 점이다. 원격 실호출은 별도 SDK와
  Inspector로 보완했고, 감리 보고서 갱신 뒤 local evidence gate 14/14를 통과했다.

릴리스 빌더는 Claude의 자기진술 필드만 보지 않도록 종료 코드 0, 출력 SHA-256,
정확한 세 도구 집합, 도구별 성공, 패리티ㆍ추적성ㆍ비영속ㆍ사람 통제 확인을 모두
요구한다. 다만 이 로컬 영수증은 제3자 전자서명이 아니며, 독립적인 외부 감사나
사람 평가를 대신하지 않는다.

- 구조화 도구 추가 전 중간 Vercel 프로덕션 `dpl_3KBirjjcmhiSz4M3WVvGXjdUq9Af`를 배포하고 고정 별칭

  일반 원격 3도구와 Claude 호환 평문 1도구를 각각 인증 후 실제 호출하고,

  기록했다. 결과 생성 후 키보드ㆍ스크린리더 초점을 검토 메모 제목으로 이동하고,

  파비콘으로 생기던 브라우저 콘솔 404를 제거했다. 최종 운영 `/web/`의
