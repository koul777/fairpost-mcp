공고문을 입력하면 검토 담당자가 수정·확인할 표현, 안내 항목, 질문이 근거와 함께 표시됩니다.

  1. 붙여 넣기 왼쪽 칸에 채용공고문을 붙여 넣거나 '예시 입력'을 누릅니다.
  2. 검토하기 '검토 메모 만들기'를 누릅니다. 공고문은 이 브라우저 밖으로 나가지 않습니다.
  3. 질문과 기록 표현·안내·네 관점 질문을 살피고 사실과 근거, 수정 이유, 다음 행동을 남깁니다.
  4. 고친 뒤 재검토 공고문을 수정하고 다시 검토한 뒤 '메모 복사'로 보관합니다.

검토 근거와 다음 행동 기록

현재 검토에 연결된 자기 기록입니다. 입력만으로 검증 완료를 뜻하지 않습니다.

질문 답변과 이 기록은 이 탭의 메모리에만 보관합니다. 새로고침·지우기·예시 입력으로 없어지므로 '메모 복사'로 별도 보관하세요. 서버·AI·브라우저 저장소에는 자동 전송하거나 저장하지 않습니다. 수정 전 기록은 답변이나 기록이 있는 검토를 최근 최대 10회까지 이 탭에서 보관합니다. 더 오래된 기록은 제거되므로 미리 메모를 복사해 보관하세요. 개인정보는 적지 마세요.

수정 전 검토 기록 보기 현재 공고에 자동 적용되지 않음

공고를 고친 뒤 '검토 메모 만들기'를 다시 누르고, 현재 결과와 이전 기록을 대조해 답변을 새로 확인하세요.

수정 전후 비교

표현·누락 안내·질문을 항목별로 비교합니다. 표시가 사라져도 검토 완료를 뜻하지 않습니다. 비교 기준은 이 탭에서만 유지되며, 지우기·예시 입력·새로고침으로 초기화됩니다.
