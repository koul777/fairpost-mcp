운영 중

FairPost 채용공고 검토 프로그램

채용공고에서 다시 볼 표현과 담당자가 확인할 질문을 근거와 함께 정리합니다. 기본 검토는 내 PC에서 실행하는 로컬 화면으로 이용할 수 있습니다.

결과는 사람 검토용 참고자료이며 공정성ㆍ법률ㆍ합격 여부를 판정하지 않습니다.

책 독자: 설치 없이 바로 시작 내 PC에서 실행하는 방법 공개 웹 앱 열기

기본 검사는 브라우저 안에서 실행되며 MCP 클라이언트나 AI 키가 필요하지 않습니다. 원문은 자동으로 서버로 전송되지 않습니다.

선택: 원격 MCP와 자체 배포
내 Vercel에 이 MCP 배포 ↗

Vercel이 공개 저장소를 복제하고 프로젝트 생성 화면을 엽니다. 원격 MCP를 열기 전에 Bearer 토큰과 허용 호스트를 설정하세요.

읽기 전용 MCP
https://fairmcp.vercel.app/api/mcp
Claude 읽기 전용 MCP
https://fairmcp.vercel.app/api/claude-mcp
전송 방식
Stateless Streamable HTTP
인증
운영 기본값은 두 MCP 경로 모두 Bearer 필수
상태 확인
/api/health

원격 MCP로 보낸 공고문은 Vercel 함수 내부의 결정론적 규칙 엔진이 처리합니다. 클라우드 AI 클라이언트에서 호출하면 해당 AI 제공자도 입력을 처리할 수 있습니다.

FairPost 애플리케이션은 원문을 파일이나 DB에 영속 저장하지 않지만, Vercel과 사용한 AI 제공자의 로그ㆍ보존 정책은 각 서비스 설정을 별도로 확인해야 합니다.

배포 후 FAIRPOST_MCP_TOKEN을 설정하세요. 명시적 공개 opt-in이 없는 운영 기본값에서는 읽기 전용 도구에도 Bearer 인증이 필요합니다.

답변 저장과 이어서 검토하기는 루프백 로컬 MCP에서만 제공됩니다.
