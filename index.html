운영 중

채용공고문을 법령 근거와 공정성 검토 질문으로 점검하는 원격 MCP 서버입니다.

내 Vercel에 이 MCP 배포 ↗

Vercel이 저장소를 복제하고 프로젝트 생성 화면을 엽니다. 현재 비공개 저장소에 접근 가능한 계정에서 배포 직후 읽기 전용 MCP를 사용할 수 있습니다.

전체 도구 MCP
https://fairmcp.vercel.app/api/mcp
Claude 읽기 전용 MCP
https://fairmcp.vercel.app/api/claude-mcp
전송 방식
Stateless Streamable HTTP
인증
전체 도구는 Bearer 필수 · Claude 읽기 전용은 무인증
상태 확인
/api/health

공고문은 Vercel 함수에서 처리되며 FairPost가 원문을 영속 저장하지 않습니다.

전체 도구 MCP를 쓰려면 배포 후 FAIRPOST_MCP_TOKEN을 설정하세요. 읽기 전용 점검에는 토큰이 필요하지 않습니다.

누구나 쓰는 공개 원클릭 템플릿으로 제공하려면 원본 저장소 또는 별도 배포 템플릿 저장소를 공개해야 합니다.
